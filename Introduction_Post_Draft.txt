[기상청 API] 실시간 날씨 & 단기예보 엣지 드라이버 공유합니다.

0. 들어가면서

SmartThings 로컬 환경인 엣지 드라이버가 도입되면서 다양한 가능성이 열렸습니다. 하지만 엣지 드라이버는 외부 인터넷망(API)에 직접 접속할 수 없다는 보안상의 제약이 있습니다. 

이 문제를 해결하기 위해 taustin님이 개발한 Edge Bridge(https://github.com/toddaustin07/edgebridge)가 등장했습니다. 이는 내부 네트워크의 PC나 NAS가 중계자 역할을 하여 외부 API 데이터를 엣지 드라이버로 전달해주는 훌륭한 솔루션입니다.

최근 지도1517님께서 이 방식을 활용하여 에어코리아 공기질 정보를 가져오는 드라이버를 만들어 주셨습니다(https://cafe.naver.com/stsmarthome/59911). 이를 보고 "기상청의 정확한 동네 날씨 정보도 엣지 드라이버로 받아와서 자동화에 쓰면 좋겠다"는 생각이 들어 직접 개발하게 되었습니다.

1. 필요사항

이 드라이버를 사용하기 위해서는 다음 준비물이 필요합니다.

1) Edge Bridge 서버 구축
   - 시놀로지 NAS(Docker)나 항상 켜져 있는 PC가 필요합니다.
   - taustin의 repository를 참고하여 설치해주세요.

2) 공공데이터포털 서비스키
   - https://www.data.go.kr/ 접속 및 회원가입
   - "기상청_단기예보 ((구)_동네예보) 조회서비스" 활용신청
   - 마이페이지에서 "일반 인증키(Decoding)"를 복사해 둡니다.

3) 우리 동네 격자 좌표 (X, Y)
   - 기상청은 행정구역별로 고유한 X, Y 좌표를 사용합니다.
   - 엑셀 파일이나 인터넷 검색을 통해 거주지의 좌표를 미리 확인해주세요.

4) 드라이버 설치
   - 아래 초대 링크를 통해 제 채널에 들어오셔서 "Weather API SpineFarm" 드라이버를 설치해주세요.
   - (채널 링크 입력)

2. 가상디바이스 세팅법

드라이버 설치 후 "주변 기기 찾기(Scan nearby)"를 실행하면 "Weather SpineFarm"이라는 새 디바이스가 생성됩니다.

디바이스 설정(점 3개 -> 설정)에 들어가서 다음 정보를 입력합니다.

- Proxy URL: Edge Bridge가 설치된 서버의 주소를 입력합니다 (예: http://192.168.0.10:1880)
- Service Key: 앞서 복사한 Decoding 인증키를 입력합니다.
- Grid X / Y: 확인해둔 격자 좌표를 숫자로 입력합니다.
- Create Another Device: 추가 디바이스가 필요한 경우 이 스위치를 켜면 자동으로 새 디바이스가 생성됩니다. (다른 지역 날씨 확인용)

3. 주요 기능 및 특징

- 초단기실황(현재 날씨): 기온, 습도, 풍향, 풍속 (매시간 15분 자동 갱신)
- 단기예보(오늘/내일): 하늘상태(맑음/흐림), 강수형태(비/눈), 강수확률, 강수량, 최저/최고기온
- 자동화 지원: 모든 데이터는 SmartThings 자동화의 '조건'으로 사용할 수 있습니다. 특히 기온 범위는 -100~100도까지 숫자 입력을 지원합니다.

4. 유의사항 및 트러블슈팅

1) 업데이트 주기
   - API 호출 제한(하루 1000회)을 고려하여 갱신 주기를 최적화했습니다.
   - 현재 날씨: 매시간 15분에 갱신
   - 예보 정보: 매일 새벽 02:15에 1회 갱신 (하루치 예보를 한 번에 가져옵니다)

2) 오프라인 상태 (Offline)
   - 디바이스가 오프라인으로 뜬다면 "네트워크 에러"입니다.
   - Edge Bridge 서버가 꺼져 있거나, Proxy URL 주소/포트가 틀린 경우입니다.

3) 업데이트 실패 메시지
   - 디바이스 하단의 상태 메시지를 확인하세요.
   - "요청 횟수 초과 (429)": 일시적인 차단이므로 잠시 기다리면 자동 복구됩니다 (디바이스는 온라인 유지).
   - "잘못된 격자 좌표 (99)": 설정에서 Grid X, Y 값을 확인해주세요.

4) 초기화 팁
   - 데이터를 처음 불러오는데 시간이 조금 걸릴 수 있습니다.
   - 설정 저장 후 약 10초~1분 정도 기다리면 데이터가 표시됩니다.

부족한 점이 많지만 날씨 자동화가 필요하신 분들께 도움이 되었으면 좋겠습니다. 피드백은 언제든 환영합니다.
